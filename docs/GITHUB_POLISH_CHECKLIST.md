# GitHub Repository Polish Checklist

## Repository Basics

- [ ] Repo name is clear: `doculedger`.
- [ ] GitHub description explains the project in one sentence.
- [ ] Repository is public only after checking for secrets and local artifacts.
- [ ] License decision is clear.

## Recommended Topics

- [ ] `ai`
- [ ] `ocr`
- [ ] `fastapi`
- [ ] `nextjs`
- [ ] `invoice-processing`
- [ ] `bookkeeping`
- [ ] `document-ai`
- [ ] `csv-export`
- [ ] `python`
- [ ] `typescript`
- [ ] `portfolio-project`

## README

- [ ] README is complete.
- [ ] Problem and target users are clear.
- [ ] Workflow is easy to understand.
- [ ] Setup instructions are tested.
- [ ] API overview is included.
- [ ] Limitations are honest.
- [ ] No production-readiness claim.
- [ ] No 100% accuracy claim.
- [ ] No official QuickBooks/Xero API claim.

## Visuals

- [ ] Screenshots added under `docs/assets/screenshots/`.
- [ ] Screenshot captions added to README.
- [ ] Demo video recorded.
- [ ] Demo video link added to README.
- [ ] Architecture diagram added if available.

## Demo And Docs

- [ ] Demo workflow document exists.
- [ ] Screenshot guide exists.
- [ ] Demo video script exists.
- [ ] Portfolio case study exists.
- [ ] LinkedIn post is ready.
- [ ] Outreach messages are ready.

## Safety

- [ ] Sample data is fake.
- [ ] No real invoices are committed.
- [ ] No `.env` files are committed.
- [ ] No secrets, tokens, or credentials are committed.
- [ ] No `node_modules` folders are committed.
- [ ] No `.next` build output is committed.
- [ ] No local SQLite DB files are committed.
- [ ] No pytest temp folders are committed.

## Validation

- [ ] Backend tests pass.
- [ ] Frontend build passes.
- [ ] Frontend lint passes.
- [ ] `git diff --check` passes.
- [ ] Git status is reviewed before commit.

## Final Manual Tasks

- [ ] Capture screenshots.
- [ ] Record demo video.
- [ ] Add video link to README.
- [ ] Publish LinkedIn post.
- [ ] Send targeted outreach messages.
